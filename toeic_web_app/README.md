# TOEIC Practice Web App

Готовая веб-страница для размещения вопросов TOEIC (Grammar Parts 1–7 и Incomplete Sentences Parts 1–2) на вашем сайте.

## 🚀 Как выложить на ваш сайт:

### Вариант A. Простая загрузка на любой хостинг / сервер:
1. Загрузите файлы из папки `toeic_web_app` в любую папку вашего сайта (например, `yoursite.com/toeic/` или прямо в корень):
   - `index.html` — главная страница приложения.
   - `toeic_data.js` — файл данных со всеми 900 вопросами и вариантами ответов.
2. Откройте эту папку в браузере — всё работает сразу без баз данных и настройки серверов!

### Вариант B. Использование сырых данных в JSON/API:
- Используйте файл `toeic_database.json` если у вас собственный бэкенд на Node.js, Python, PHP или WordPress.

## 📱 Особенности приложения:
- **Все 9 категорий** тестов TOEIC (900 вопросов).
- **Интерактивное прохождение**: выбор ответа, моментальная подсветка правильного/неправильного ответа, навигация «Вперед»/«Назад».
- **Итоговый результат**: подсчет процента правильных ответов и баллов.
- **Адаптивный дизайн**: идеально отображается на смартфонах, планшетах и компьютерах.
- **Работает оффлайн**: без зависимостей от сторонних API и внешних баз данных.
